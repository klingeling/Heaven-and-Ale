# 天堂与美酒 · 浏览器桌游

《天堂与美酒》的浏览器原型，使用 React、Vite 与 boardgame.io。界面使用工作区 `Images/` 中的棋盘与组件素材。

## 启动

需要 Node.js 18 或更新版本。

```bash
npm install
npm run dev
```

这会启动本地热座模式。要开放线上房间，在另一个终端启动 boardgame.io 服务端：

```bash
npm run server
```

服务端默认监听 `http://localhost:8000`。朋友需要能访问这台机器的服务地址；如果在不同网络，需要在服务器和网络层开放该端口。也可在首页更改服务器地址。

## 当前模式

- **本地热座**：2–4 人共享设备，使用同一浏览器轮流操作。
- **线上房间**：创建或加入 boardgame.io 房间，并使用房间号分享给朋友。
- **机器人接口预留**：游戏状态和合法行动集中在 `src/game.ts`，可通过 boardgame.io 的机器人 API 添加策略。首页“单人练习”入口目前是本地对局席位占位，不会自动执行机器人行动。

## 规则实现进度

已实现回合轨道移动、资源/僧侣购买、阴凉与向阳费用、基础资源激活、棚屋邻接结算及奖励、酒桶目标检查、特权卡和轮次推进。开局时首位玩家在无奖励的起始玩家格，其余玩家逆时针选择其余起始奖励格；回到起点时也要选择空位并领取奖励，首位玩家格决定下一轮的起始玩家。主板会显示玩家标记。每轮会把新板块加入公共轨对应的 15 个资源格和 4 个僧侣格；落点后选择该格的一块供给（只有一块时自动选中），随后玩家板高亮所有付得起的空位，点击位置即可按该格的阳/阴面规则购买并放置。四个僧侣格阴面价格依次为 4、3、2、1，阳面价格翻倍。资源板块的奖励只在激活时结算。玩家板采用 TTS 模组 Lua 的 30 个花园吸附点和 7 个棚屋吸附点，并按原始玩家板图校准叠点；公共轨和站点按主板图校准显示位置。

这是第一版可交互原型。僧侣链式激活、公共计分标记供给与落点对应、大小酒桶竞争供应、首位玩家起始奖励，以及终局资源交换和完整计分仍需按规则书逐项校准；当前终局分数是简化版。
